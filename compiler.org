* MIRICL compiler

MIRICL shares a Common Lisp frontend, target type rules, semantic optimizer and Wasm emitter
between the compiler running inside Wasm and host bootstrap tooling. Compact HIR also supplies
portable execution. Whole-program analysis retains reachable definitions and ordered
initialization effects, then emits portable or native bundles. This document describes current
mechanisms and interfaces; AGENTS.md supplies project-wide semantics and development rules.

** Interfaces and bootstrap

=compile-to-hir= lowers a lambda to semantic HIR; =compile-hir= produces an interpreted
function. =emit-hir-code= and =load-hir-code= expose checked retained code.
=emit-native-module= emits Wasm, literals and available debug metadata. =compile-native=
compiles and instantiates a lambda; =compile-native-hir= compiles retained HIR without
reconstructing source.

=compile-module-to-hir= accepts DEFUN forms and explicit entry points. =compile-native-module=
returns entry functions, bytes and HIR for a sealed module without changing global bindings.
Internal calls and FUNCTION references resolve lexical definitions; symbol designators retain
global lookup. Top-level evaluation and loading remain separate operations.

=miricl-compiler:*compile-evaluations*= controls REPL, EVAL and source LOAD boundaries. Native
policy compiles executable forms while processing top-level PROGN, EVAL-WHEN, definitions and
environment changes in order. Explicit =:interpreted= and DEBUG 3 use checked HIR execution.
NIL retains the source route for bootstrap and remaining lexical adapters. A guard prevents
compiler preparation from recursively compiling itself. Macro expansion and load-time
evaluation use target objects and dynamic bindings; failures propagate.

=miricl.wasm= links the precompiled compiler and starts =:ready= with origin =:image= .
=miricl-cold.wasm= retains the source compiler for interpretation and bootstrap.
=miricl-interpreter.wasm= supports scripting, portable code and native module loading without
the optimizing compiler. The source evaluator still serves bootstrap, NIL evaluation, source
closures and macro preparation. ASDF is loaded explicitly. The default browser image must
remain below 1 MiB raw; compressed download size is a separate concern.

The required bootstrap runs the compiler interpreted inside Wasm, compiles its kernels, and
compiles its definitions into a sealed native payload with shared literals and lexical
bindings. =ensure-compiler= coordinates requests, records failure or completion, and avoids
recursive bootstrap. Explicit =:interpreted= state preserves live source definitions.
Node/browser adapters instantiate emitted modules; WASI executes linked code and portable
FASLs but cannot load generated native code dynamically.

=miricl/cross= loads the same frontend, proofs and emitter on the host without a guest
bootstrap. =miricl-cross:compile-lambda= emits target bytes, literals and debug metadata;
=compile-module= also returns HIR. They neither install host definitions nor execute target
code. Target macro and LOAD-TIME-VALUE adapters are explicit; host expansion and EVAL are not
target semantics.

** Frontend, ownership and policy

The frontend assigns identities to lexical bindings, functions and control targets. FLET uses
the outer function environment; LABELS shares recursive bindings. Lambda normalization
preserves initialization order, declarations, optional/keyword processing, supplied-p
variables and argument checks. TYPE and THE attach scoped assertions; nested assertions
intersect and rebinding creates a new identity. FTYPE result types do not prove value counts.

Untrusted source, macroexpansions, public HIR and serialized data are validated before
unchecked internals: structure, cycles, names, types, ownership, bounds, SSA dominance and
control edges. Literal graphs may share or cycle where permitted. Diagnostics identify
offending input with bounded summaries. Fresh compiler-owned HIR need not be revalidated
between passes, but changed edges require predecessor maintenance. Public consumers validate
on every entry; no certificate survives external mutation. Admitted declaration/type syntax is
snapshotted before callbacks can mutate shared source; literal identities and opaque type
arguments retain their intended sharing.

SAFETY and DEBUG retain lexical scope through deferred work and inlining. SAFETY 0 permits
declaration-based unchecked lowering without bypassing public validation. DEBUG 0 permits
eligible frame omission; DEBUG 2 retains native listings; DEBUG 3 selects interactive HIR.
SPEED, SPACE and COMPILATION-SPEED are retained separately from those contracts.
Whole-function policy summaries let local speed-oriented regions veto outlining. The compact
deployment policy is =(optimize (space 3) (speed 1))= ; STRIP and visibility remain explicit.

Inlining uses the caller's growth policy while preserving the callee's lexical bindings,
declarations, SAFETY and DEBUG. INLINE encourages bounded expansion; NOTINLINE vetoes it;
=:inline nil= disables automatic module inlining. The current estimator weights residual
calls, argument/result traffic, literals, indices and adapters, and prunes IF arms for narrow
literal-argument facts. It assumes out-of-line bodies remain and gives no sole-call removal
bonus. This is a weighted approximation, not exact complete-module costing. Original syntax,
nesting, total work and growth are bounded; opaque forms, macros and unsupported literals
decline estimation. It does not expand macros or execute user code. COMPILATION-SPEED controls
work independently of growth policy.

** Semantic HIR and proofs

HIR contains functions, blocks, SSA values, cells, captures and explicit transfers.
Instructions carry effects, scoped safety and available origins; multiple-value groups remain
distinct from primary values. Dynamic bindings, cleanup regions and nonlocal targets are
explicit. Retained bytecode keeps register identity, block metadata, literals, policy and
captures while omitting lowering-only source environments and producer structures.

Checked readers serve execution, disassembly and native reconstruction. Loading copies
executable containers once into private storage. Reconstruction checks externally determined
operand, parent, register and control contracts, then recomputes analysis. Private
=emit-hir-code-checked= and =%%hir-function-checked= avoid a serialization round trip only for
fresh owned containers; public emission and loading remain checked. The interpreter has fixed
small-call encodings, primary-call specialization and a bounded transient decoding cache
excluded from snapshots. Full-value and debugger calls retain their general protocols.

=hir-types.lisp= shares target relationships across inference, proof queries and lowering:
nominal families, unions/intersections, EQL/MEMBER, MOD, integer intervals, array rank and
element types. Opaque types remain unknown; proofs do not call host SUBTYPEP, expand arbitrary
DEFTYPE or execute SATISFIES. EQL identity and cyclic literal handling remain intact.
Depth/work limits yield no proof on exhaustion. Fresh inference propagates local values,
ranges, joins and closed-call arguments/returns while accounting for outside callers at
entries and escapes. HIR changes invalidate dependent facts.

Dominated truth tests and canonical predicates narrow values only across paths that establish
the premise. Aliases, writes, captured landings and unresolved entries prevent unsupported
propagation. Executed truth facts are available at every SAFETY level; unchecked declarations
retain their own restrictions. Arithmetic uses target intervals, contagion and bignum
promotion. Fresh CONS field observations and proper-list facts are temporary and invalidated
by mutation or unknown effects; LIST alone never proves a proper spine.

Semantic simplification forwards unaliased private cells, propagates constants and executable
edges, forwards empty blocks and preserves scoped assertions. Bounded branch-tail sharing
sinks matching suffixes of exclusive sibling arms in an acyclic graph, with identical dynamic
environments and corresponding SSA operands, literal/type identities and safety. It excludes
environment/capture changes and never moves work before an arm's prefix. The losing suffix
remains unreachable retained-HIR producer inventory: native reachability drops it, but
portable bytecode need not shrink.

** Native values, calls and control

Lisp values use WasmGC =eqref= ; raw numeric locals remain separate. Function objects retain
literals, captures, entry identity and available debug metadata. Public entries check a
function-and-argument packet. Eligible fixed-arity private workers use five reference
parameters: function context plus four operand slots. Checked adapters retain public arity
behavior and verify actual signatures before attachment; metadata never authorizes casting an
arbitrary funcref. This is not a variable-width or general wide-argument ABI.

Known exact calls reuse private argument-use masks to omit unused value roots and pass NIL in
unused physical slots. Producer effects, errors and evaluation order remain live. A bounded
closed-use audit can trim private returns to their primary value, excluding roots, exports,
escapes, captures, full-value uses, barriers and debugger/custom-worker contracts. Scalar
VALUES then roots only its first operand; discarded producers still execute when observable.
Analysis is emission-local, avoids recursive mask planning and invalidates affected caller
plans. Public and escaping entries retain complete values.

Result-count proofs independently distinguish zero values from one NIL. Executable VALUES,
copies, equal-count joins and proved closed calls can give exact counts; FTYPE cannot.
Eligible DEBUG 0 fixed-arity callees with a proved small result tuple and actual closed
consumers can use native multiple-result workers. Primary/full/tail/join consumers use
component locals; ordinary boundaries pack values. Failed signature-preserving rewriting falls
back. General primary/discard calls use =native-primary-call= and clear secondary state after
success; full consumers retain =native-call= .

Direct closed calls and frame omission require the applicable effect/debug contract. Dynamic
state, cleanup, captured exits and unknown calls retain ordinary dispatch. Global calls
resolve live bindings at the required point; operand effects cannot be moved across
resolution. Canonical INLINE lowering checks the selected primitive, and ordinary
specializations guard replacements with generic fallback. Method specializers alone are not
body type assertions: public METHOD-FUNCTION calls bypass generic applicability, and class/MOP
changes invalidate unguarded class assumptions.

Tail calls whose complete group flows to return use Wasm tail-call operations for supported
lexical and computed native callees, including FUNCALL/APPLY/MVC. Checks, global redefinition,
values, dynamic cleanup and scheduler polls remain. Unsupported calls use ordinary
application. Immutable captures can be direct; mutable captures share cells. Distinct function
objects and required capture identities survive body sharing and closure caching.

Integers are canonical i31 immediates, boxed signed-i64 values or larger sign/magnitude
integers; target FIXNUM spans signed i64. Proven scalar work can stay raw and share canonical
boxing. Overflow, large shifts, division traps and infinite two's-complement semantics retain
checks or general helpers. Private numeric cells require proofs for every write and no
capture/escape; reads keep SSA snapshots. Predicates can feed branches directly; bounded reuse
and loop motion require stable operands and nontrapping canonical operations. Typed
list/vector operations retain safety, definition and boundary contracts; LIST/LIST* preserve
fresh spines and operand order. APPLY/MVC binding rewrites check proper lists and arity before
unchecked reads.

Acyclic regions use forward structure; proved reducible natural loops use Wasm loops.
Irreducible, captured or exhausted cases retain dense dispatch. Transfers preserve block
arguments/environments and backedge scheduling. Native body passes perform liveness, local
coalescing, copy/constant folding, stackification and scope simplification without moving
effects or traps. Shared Lisp and Wasm kernels implement these passes. Module compaction pools
literals, merges equal bodies, removes unreachable code/imports and relocates all references.
Helper fusion and factory/table selection price encoded section costs. Runtime imports use
namespace =m= and omit the =native-= field prefix.

** Whole-program artifacts and runtime

COMPILE-FILE records =:miricl-ir= definitions, references, effects and reflection barriers.
=analyze-file= reconstructs definition IR without loading application code. Explicit
entries/retention root reachability; package exports alone do not. Calls, designators,
globals, classes, methods and load-time recipes add dependencies. Unknown initialization and
observable creation remain ordered roots; missing metadata or unbounded reflection
conservatively retains code. =shake-file= and =optimize-system= combine reachability with
graph compaction. =:strip nil= retains supplied definitions; it does not disable
representation compaction. =compile-native-bundle= emits initializers/closures, and =:load t=
executes each initializer before decoding the next dependent unit.

=fasl-format.lisp= writes indexed units in =miricl.fasl= custom sections with =MIRF= headers,
roots, object blocks and optional analysis/definition indexes. Unit-local references preserve
sharing/cycles. Checked directories, extents, counts, tags and references precede use.
Canonical lexical naming and graph pooling preserve quoted, uninterned, mutable and load-time
object identities. Native units share modules while keeping distinct literals/function
objects. Images retain reachable Lisp state, native bytes and captures, excluding transient
scheduler/decoder caches. Only matching current formats are supported. Bootstrap source
packing is separate, bounded and checked, and uses target symbol identities rather than
host-private names.

Runtime CL kernels compile as sealed groups above representation/platform WAT. The kernel
linker checks dependencies, ownership, captures and signatures; public validation precedes
unchecked traversal. Fixed-callback proofs require immutable private ingress and reject
replacement, capture, escape or unknown provenance. List/sequence/stream/package/metadata
kernels share compiler sources; remaining representation adapters stay native until equivalent
lowering is suitable. Host tooling is not a shipped runtime dependency.

Runtime multiple values use small slots/native tuples and checked owned overflow storage,
preserving full values across callbacks and unwind. Lexical binding views share mutable cells.
Generic dispatch retains live method, version, class and MOP guards and escaped next-method
context. HIR debugging shares visible cells with closures, checks declared writes and uses
ordinary nonlocal cleanup. Frame metadata is copied/validated; executable arrays are not
exposed. Native Wasm does not yet provide equivalent stepping instrumentation.

** Source map and validation workflow

- =compiler-input.lisp=, =hir.lisp=: validation, frontend, declarations and HIR.
- =hir-types.lisp=, =hir-optimize.lisp=: target proofs and semantic transforms.
- =hir-code.lisp=, =hir-interpreter.lisp=, =hir-reconstruction.lisp=: retained code.
- =wasm-compiler.lisp=: native planning/emission and compiler bootstrap.
- =wasm-optimizer.lisp=, =wasm-module-optimizer.lisp=: body/module passes.
- =whole-program.lisp=, =fasl-format.lisp=: definition IR, bundles and codec.
- =cross-compiler.lisp=: target adapters and runtime-kernel linking.
- =evaluation-library.lisp=, =compiler-library.lisp=: evaluation/file integration.
- =runtime-hir.lisp=, =runtime-native-code.lisp=, =runtime-values.lisp=,
  =scripts/miricl.mjs=: runtime execution, installation and image boundaries.

Iterate in persistent source-compiler Wasm and host cross-compiler REPLs, then confirm with
matching precompiled images and application checks. Sealed native callers may retain old
definitions after global redefinition. Runtime/import changes require matching images; host
reloads must refresh packed source catalogues as well as image caches. Layout/registration
changes require a fresh image check. DISASSEMBLE handles retained HIR; =disassemble-native=
accepts emitted bytes and actual function index without changing policy.

ANSI covers language behavior in interpreter/compiler modes. Focused soundness, optimization
and implementation suites cover rejection/recovery, proofs, redefinition, values/effects, tail
calls, codecs and platform boundaries. WASI runtime tests stay separate from dynamic-code
optimization requirements. Gate analysis on eligible consumers, count its own shipped cost,
and avoid broad frameworks without representative measured return. Compare a fixed original
source corpus without installing successive compiler generations; keep experiment
drivers/results temporary and report bootstrap, native throughput, application behavior and
raw/compressed sizes separately.
