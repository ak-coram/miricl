* Game of Life

From the repository root, prepare the runtime and ASDF artifacts and Quicklisp
source symlinks:

#+begin_src sh
just setup-game-of-life
cd game-of-life
just dev
#+end_src

Open http://127.0.0.1:8000/dev.html. Click and drag to draw or erase cells;
Run/Pause and Step control the simulation. The 24×16 grid wraps at its edges.
The colors follow Plan 9 / Acme.

=just dev= accepts HTTP and WebSocket ports, followed by additional REPL
flags. For example, =just dev 8001 4007 --repl-bridge= also enables the
TCP REPL. Open =http://127.0.0.1:8001/dev.html?ws=4007= in that case.
Wasmtime's command derives its directory preopens from the symlinks.

The browser and terminal share the same Lisp state:

#+begin_src lisp
life:*world*                 ; prints the current world as an ASCII grid
(life:print-grid)            ; just the grid, with # for life and . for empty
(life:world-generation life:*world*)
(fset2:size (life:world-cells life:*world*))

(defparameter *snapshot* life:*world*)
(setf life:*world* (life:paint life:*world* 4 5))
(life:render)
*snapshot*                  ; the old world is unchanged
#+end_src

=life:paint=, =life:seed= and =life:next-generation= return new values using
FSet 2 persistent sets. Only the UI boundary replaces =life:*world*=.
ASDF can reload edits with =(asdf:load-system "game-of-life")=.

Build the production application:

#+begin_src sh
just build
#+end_src

Development loads =miricl.wasm= in the browser. The shipped WASI
command serves files and forwards REPL forms; the browser selects compilation
or interpretation using =miricl-compiler:*compile-evaluations*=, initially =t=.
Production builds run the precompiled compiler image in Node.
The build prunes the ASDF system and compiles its retained functions and
initializers to WASM with =--native=, then copies
the production HTML, adapter and runtime into =build/=. Publish these four files
together: =index.html=, =miricl.js=, =miricl.wasm= and =game-of-life.wasm=.
=build/retention.txt= explains which definitions the optimizer keeps.
=dev.html= loads source files through the development server instead.

The application uses the =fset2= package from Quicklisp's FSet system.
Setup links the runtime distribution, compiled ASDF and dependency sources;
it does not require copying MIRICL's repository into the application.
A small MIRICL locking port is appended to FSet's =port.lisp= in the guest
filesystem; the Quicklisp checkout is untouched.
The named-readtables port omits its PAX documentation component and dependency,
so the production FASL needs no ASDF/UIOP library.
