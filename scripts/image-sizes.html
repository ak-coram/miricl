The REPL and TODO HTML pages are standalone files, including their interpreter and adapter. Game of Life serves four separate files: HTML, JavaScript adapter, interpreter and application FASL. Its total sums those files, compressing each separately. The Lisp payload row is already included in that total. Maxima's total includes its nine startup files, including the optimized Lisp core. FriCAS's total likewise counts twelve startup files, with the complete on-demand algebra library and command help. Maxima documentation and test suites are excluded from its distribution. On GitHub Pages, the REPL is named index.html.

miricl.wasm contains the interpreter and compiler source, compiled on first use. miricl-precompiled.wasm includes the size-optimized native compiler and defaults to compiled evaluation in browsers and Node. miricl-repl.wasm includes the precompiled compiler for Node and WASI. miricl-asdf.wasm is the optional ASDF and UIOP library, with its complete interface retained. Game of Life currently retains all definitions because dynamic function lookup triggers conservative retention. Its size reduction comes from compaction and sharing.

Maxima retains its complete dynamic environment for arbitrary REPL expressions and package loading. The optimizer compacts constants and code and removes compiler indexes; it does not restrict the available mathematics.

When an ACL2 build is present, its total includes the native compiled core, runtime and compressed system sources. The native core does not yet contain an initialized logical world; prover bootstrap remains unverified. Selected math book sources and their dependencies are a separate download, fetched on first access and compiled by the user on demand. Each included source file is at most 2,000,000 bytes. Already compressed archives are measured as served files.

How these sizes are measured

Raw sizes are exact file lengths. Gzip uses level 9; Brotli uses quality 11. The web server chooses which compression to serve. 1 KiB = 1,024 bytes.

Inside the Wasm images

Section sizes include their binary headers. Repeated section names are combined; each byte is counted once. The file header is listed separately.
